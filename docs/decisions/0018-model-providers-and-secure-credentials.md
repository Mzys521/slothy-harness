# ADR 0018 — 前端模型提供商、任务绑定与安全凭据

日期：2026-10-06  
状态：已实施

## 问题

桌面模型由环境变量固定，用户无法在前端配置提供商或切换模型。直接把 API Key 写入工作区 JSON/SQLite、任务快照或前端偏好会传播凭据；全局切换模型后重新组装旧任务会改变执行或审批恢复的目标。

## 决定

1. 提供 DeepSeek、Qwen、MiMo、GLM 官方预设。设置页配置密钥、服务区域和文本模型，输入区仅提供模型快捷选择；工作模式入口仍只在侧栏顶部。支持账号模型列表刷新和手动模型 ID，不开放任意 Base URL。
2. Application `ModelService` 负责边界校验、用户归属、无密钥配置与当前选择。凭据、SDK、验证与 Runtime 工厂由组装根注入；保持 Presentation → Application → Core 单向依赖。
3. Infrastructure `ProviderCredentials` 在 Windows 使用用户级 DPAPI 加密和原子文件替换，其他平台明确采用进程内凭据。用户/提供商/服务区域各自隔离；错误只包含安全说明，不覆盖损坏凭据，不写明文。
4. 配置只返回 `configured`，不返回密钥、掩码或凭据指纹。用户输入仅通过 UI 设置接口传入宿主，成功/失败操作结束或切换提供商时清空，不注册模型工具，不进入模型上下文。
5. 每个新任务固定 provider_id、endpoint_id 和 model。General Runtime 按预算/模型缓存；Coding Runtime 再包含项目目录与权限绑定。已保存任务恢复通过原模型绑定路由；凭据在每次调用时从安全存储读取，支持轮换且不进入 Core/快照。旧环境和无绑定任务保持兼容。
6. 四家通过统一的中立 Chat Completions 转换复用流式、用量与函数工具调用。关闭深度思考，以匹配 Core 不携带 reasoning_content 的契约；不引入空推理或恢复接口。增量工具参数逐片拼接，不能去掉相邻重复字符。
7. SDK 无自动重试，不跟随重定向；Runtime 继续管理有限重试。连接测试使用独立的固定短提示，不附带用户任务或工具，仅在用户明确点击时执行。

## 结果与验证

用户只填写 API Key 即可使用默认模型，配置生效无需重启。浏览器可切换同一提供商的模型及不同已配置提供商，旧 Run 的模型、目录和权限不变。标准文本 API 为当前范围；供应商专用 Coding Plan、任意兼容端点、推理字段、自动同步 RAG 凭据不在本次范围。

测试采用临时目录和假密钥，真实 SDK 通过 MockTransport 验证四家 JSON/SSE、工具执行、切换、错误脱敏、恢复和凭据隔离。Windows 直接验证 DPAPI 密文及重新读取；Core 测试不访问外部网络。操作说明及官方来源见 [模型提供商](../model-providers.md)。
